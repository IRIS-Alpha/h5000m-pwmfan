## 三、追加提案（2026-11-22 登记，待核查）

### 顶部区域

- 页头合并为一行：左侧“风扇控制”标题 + “运行中”状态徽标（徽标宽度贴合文字、左对齐）；右侧主题交换器与语言交换器。
- 主题交换器：自动 / 亮 / 暗，照搬 21st.dev Theme Switcher 样式。
- 语言交换器：`CN` / `EN`，样式照搬同款（与 §15 的三选方案冲突，待移动端排布确认）。
- 待核查异议：真实 LuCI 页头与菜单标题已存在，应用内再加“风扇控制”可能造成重复标题；预览壳顶部“Vantage · H5000M V3 · 模拟数据”不属于插件界面。

### 模式选择

- “快速调度”改名“模式选择”。
- 选中态从子元素移到整个模式容器；高亮改为边框流光，并用红/绿指示区分已选与未选。
- “固定请求”“曲线预设”标题行右侧显示 `[绿]已选` / `[红]未选` / `[黄]应用中-3S`（黄色态带尾随合并倒计时，如“应用中-3S”“应用中-1S”）。

### 固定请求与滑块

- 区域改为三行：标题/状态行；“请求占空比”标签 + 百分比读数；`[−] 滑块 [+]`。
- 加减按钮与滑块同为 1% 步进，保留吸附；删除尾随百分比读数，改为滑块上的浮动读数气泡（参考 P Slider、Slider）。
- 略增三行之间的间距。
- 停转警示与“高温区曲线过低”是两套独立判定，可同时出现，任一命中即显示中间那句居中标语：同一行右侧右对齐两个文本框（黄框黄字“高温区曲线过低”、红框红字“停转”），行中间居中显示无框提示“过高的温度可能影响设备硬件寿命”；未触发时隐藏；开发预览先强制显示。
- 判据（2026-11-22 确认）：停转按实时温度对应的请求占空比判定，为 0% 而且实际输出为 0 时才显示（固定请求 0% 同样算停转，但过温保护、故障全速把输出抬高时不显示，不能因为选了固定请求 0% 就锁定停转）；高温区曲线过低 = 高温区（≥60°C）任意区域存在低于 50% 的占空比请求；低温区 < 40°C。这些是预览判据，不是固件阈值。

### 折叠参数与图表

- 目标驱动、自定义曲线与温度历史的参数区存在文字排版和视觉对齐问题，需统一标题、说明、字段基线、折叠箭头与内容间距。
- 曲线图本身暂无重做需求；优先检查温度历史底部的窗口/采样设置排列、字段宽度与单位间距。

### 仪表盘操作区与高级设置

- 仪表盘缺少 LuCI 的“重置 / 保存 / 保存并应用”操作区。
- 高级设置新增“模式最小应用间隔”，默认 3 秒。
- 高级设置文字与分组视觉干扰多，需要一套可复用的标题、说明、字段、危险/状态提示模块样式。

## 四、待确认（不构成规范）

1. 应用模型：已定案为“分控件 + 前两层合并（松手提交、3 秒尾随合并），不做后端步进限幅”，见 `REQUIREMENTS_V3.md` §16。
2. `mode=off` 去留：**已定案并完成**（2026-11-22）。只读核对显示路由器只有 `mode='quiet'`、不存在 `off` 配置，因此直接删除了白名单里的 `off` 与别名分支；存量 `mode=off` 配置今后会按无效配置进入全速故障态，这一代价已写入 `docs/REQUIREMENTS_V3.md` §12。
3. “待应用”状态来源：已选/未选来自 UCI，待应用必须来自真实提交队列（3 秒合并窗口或提交流程），不能只做视觉。
4. 语言控件：三选方案与 `CN/EN` 二选方案二选一。
5. 判据落到实现的取数口径：停转取“当前温度下的请求输出与本次实际输出都为 0”；“曲线过低”按活动模式在高温区的请求判定，还是只看曲线本身的形状。
6. 主题交换器：主题偏好由 `vantage_theme` UCI 持有（`menu-vantage.js` 通过 `callLookSet('vantage_theme','appearance',…)` 写入，值 `auto/light/dark`），插件内再造开关会产生第二个状态源。

### 应用模型建议（待确认）

| 控件 | 建议策略 | 理由 |
| --- | --- | --- |
| 模式 / 曲线预设切换 | 3 秒尾随合并；选中态立即更新，标题行显示“应用中-Ns” | 连点会写多次 overlay 配置并造成多次 PWM 阶跃；合并只留终态 |
| 固定请求滑块 | 松手提交，并进入同一个 3 秒合并窗口；拖动只更新读数；0% 绕过合并立即提交 | 手速档的中间值不进配置，停转不等待冷却 |
| 高级设置表单 | 保持“保存并应用” | 多字段编辑需要显式提交点 |
| 历史图窗口 / 采样间隔 | 本地即时生效，持久化写入可合并 | 纯展示设置 |

配套：提交在 `pagehide` / `visibilitychange` 时冲刷，避免关页丢失；“应用中-Ns”在状态回读确认后消失。
