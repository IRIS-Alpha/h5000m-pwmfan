## 一、四项既有问题

### 1.1 320px 温度历史图刻度重叠 — 确认

- 实测：320px 视口下画布 266 CSS px、轴跨 212px、刻度间距 42.4px、11px 等宽字体标签宽 32.2px。
- 根因：`htdocs/luci-static/resources/view/h5000m-pwmfan.js:470` 让首尾标签分别左对齐与右对齐，中间标签居中；端点标签与相邻标签的重叠量为 `1.5 × 标签宽 − 间距 = 5.9px`，出现在 `04:58` 与 `05:01`、`05:10` 与 `05:13`。
- 判据：重叠只在画布宽 `< 296px`（约 310px 视口）时出现；390px 起间距 56.4px，不再复现。
- 方向：端点标签向内缩进，并按可用宽度降级格式或刻度数量。

### 1.2 390px 高级设置保存工具栏遮挡 — 确认，根因是选择器不匹配

- 实测 390×844：滚动到 0/272/543/815/1086px 时，工具栏分别覆盖 46/42/44/44/5px 的表单内容，涉及"全速保护温度阈值""温度回差""启动助推输出""控制采样与曲线来源"。
- 根因：`htdocs/luci-static/resources/view/h5000m-pwmfan-advanced.js:41` 的 `.pwmfan-advanced .cbi-page-actions{position:static}` 永不匹配，因为工具栏是 `.pwmfan-advanced` 的兄弟节点（`main.preview > div > .cbi-page-actions`）。主题规则实际生效：`.cbi-page-actions { position: sticky; bottom: var(--sp-4); z-index: 150 }`，背景半透明。
- 判断：固定操作栏是 Vantage 的既有约定，其它 LuCI 页面同样如此；缺陷在于本页既不补偿底部空间，又用无效选择器试图覆盖主题。
- 方向：遵循主题约定，给页面容器补 `padding-bottom`（约 `var(--sp-4)` 加控件高度），并删除无效覆盖。

### 1.3 主页与高级设置视觉语言 — 部分确认

确认：
- 重复标题：高级设置先渲染视图自绘的 `<h2>高级设置</h2>`（20px/600，y=49），再由 `form.Map` 渲染 `<h2>风扇高级设置</h2>`（24px/600，y=154），表单标题比页面标题更大，层级倒置。

未复现：
- "深色主题返回按钮仍呈浅色"：实测浅色为 `#4b6600` 文字 / `#eef0f3` 底 / `#c1c7ce` 边框，深色为 `#c8f031` / `#22252a` / `#353a41`，随主题正确切换。此前观察来自预览主题切换动画未稳定时的采样，需在设备上复核后再定性。
- 仍值得处理的是语气与层级：返回链接是 `a.btn`，取强调色并带按钮外观，与页面标题并列；建议改为次级文本按钮或移入页头左侧。

### 1.4 移动端预设 3+2 — 确认，但目标排布需重新定义

- 实测 320/390/500 均为 3+2 且右侧留空，651px 起单行。

## 八、V4 追加提案核查（2026-11-22）

只读核查，不改代码。可用内容宽 = 视口 − 页面内边距：320px → 286，390px → 356。

### 1. 页头一行在 320px 不成立

| 元素 | 实测宽度 |
| --- | --- |
| “风扇控制”（标题字号） | 84 |
| 徽标“运行中” | 71 |
| 徽标“运行中 · 插件控制” | 134 |
| 三选主题交换器（图标态，3×26+2） | 约 80 |
| CN/EN 交换器（2×30+2） | 约 62 |

短徽标组合 84+71+80+62+3×6 = 315 > 286 放不下；带来源徽标 378 > 286。390px 下短徽标组合 315 < 356 可以，带来源徽标 378 仍不行。结论：320px 必须降级，或把两个交换器收成图标按钮/弹出层。

### 2. 同一页会有三种叫法

Vantage 顶栏在小屏只保留最后一个面包屑（`vantage.css:3376-3377`，`.vt-crumbs > :not(:last-child){display:none}`，`.vt-crumb-current` 用 `--fs-md`），即菜单项标题 “Dashboard” / “Advanced Settings”。页面内再加“风扇控制”，同一页会出现面包屑 Dashboard、h2 “H5000M PWM Fan”、新标题“风扇控制”三种叫法。要么把 `menu.d` 的两个标题改成与页内一致并补 zh-cn 翻译，要么不新增页内标题。

### 3. 主题交换器与主题自身重复

Vantage 顶栏已有调色板入口（`menu-vantage.js` 的 `.vt-pal`、`.vt-pal-list`），偏好写在 UCI 配置 `vantage_theme` 的 `appearance`（取值 auto/light/dark，走 `uci.revert` → `uci.set` → `uci.commit`）。插件内再造一个交换器会形成两个入口写同一状态，还要给插件 ACL 增加 `vantage_theme` 写权限。建议插件只做语言交换器，明暗沿用主题入口，或在页内放一个只触发主题入口的镜像按钮。

### 4. 警示行在 320px 放不下

黄框“高温区曲线过低” 99 + 红框“停转” 41 + 标语 173 + 两处间距 16 = 329 > 286。390px（356）刚好容纳。320px 需改为两行（标语一行、两个框右对齐一行），或缩短标语。

### 5. 折叠参数区的排版问题已定位

`details.pf-parameters` 内：输入框高 34px、圆角 7px、背景 `rgb(248,249,250)` 与卡片同色，只靠 1px 边框分隔；“应用目标”按钮高 36px、同样圆角同背景同边框，视觉上与输入框无法区分，且比输入框顶部低 2px、高 2px，形成错位。建议按钮改用次级按钮样式并与输入框同高，输入框背景在亮色下改白、暗色下加深。

### 6. 其它

手动曲线编辑的 `.pf-point` 为三列网格（`.pf-point{grid-template-columns:auto 1fr 1fr}`），320px 下会明显拥挤；历史设置行在 ≤400px 换行成两行（已记录）。
